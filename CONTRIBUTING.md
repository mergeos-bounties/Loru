# Contributing to Loru

Thank you for your interest in contributing!

## Getting Started

1. Fork this repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/Loru`
3. Install dependencies: `npm install`
4. Create a branch: `git checkout -b fix/your-fix-name`

## Making Changes

- Write clear, focused commits
- Add tests for any new functionality
- Ensure `npm test` passes before submitting

## Submitting a Pull Request

1. Push your branch: `git push origin fix/your-fix-name`
2. Open a pull request against `main`
3. Fill in the PR template
4. Reference the issue number in your PR description

## Code Style

This project uses the existing code style. Please follow the patterns already in the codebase.
