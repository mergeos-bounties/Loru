# Contributing to Loru

Thank you for investing your time in contributing to our project!

## Quick Start

1. Fork the repository
2. Clone your fork locally
3. Install dependencies: `npm install` (if applicable)
4. Create a new branch for your feature or bugfix

## Testing

Please ensure your changes pass existing tests. Run `npm test` before submitting a pull request.

## PR Checklist
- [ ] Code follows existing style guidelines
- [ ] Tests pass
- [ ] PR description explains the problem and the solution

## Claiming MRG Bounties

To claim a bounty, follow the [MergeOS Claim Flow](https://github.com/mergeos-bounties/mergeos). Remember to link your issue in the main claim ticket!
